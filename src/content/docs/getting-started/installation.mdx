## Requirements

- PhpStorm 2025.1 or newer, or another JetBrains IDE (such as IntelliJ IDEA or WebStorm) from version 2025.1.
- A JetBrains Account, to start the trial or activate a license.

## Install from the IDE

<Steps>

1. Open **Settings** (<kbd>Ctrl+Alt+S</kbd>, or <kbd>⌘,</kbd> on macOS) and go to **Plugins**.

2. On the **Marketplace** tab, search for **Invisible Notes** and click **Install**.

3. Invisible Notes is a paid plugin, so the IDE asks you to activate it. Start the **free 30-day trial**, or activate
   a license you've bought. See [Pricing and trial](/invisible-notes/licensing/pricing/).

4. If the IDE asks you to restart, do so.

</Steps>

That's it: right-click any line in the editor and you'll find **Add Invisible Note**. Continue with
[Your first note](/invisible-notes/getting-started/first-note/).

<Aside title="Uninstalling">
	Uninstalling the plugin doesn't delete your notes. They stay on your computer, and come back if you install
	Invisible Notes again. See [Where notes are stored](/invisible-notes/guides/storage/).
</Aside>
