## The plugin

- **Your notes stay on your computer.** They're stored in a local folder (see
  [Where notes are stored](/invisible-notes/guides/storage/)) and are never uploaded anywhere.
- **No network connections.** The plugin doesn't connect to the internet, and doesn't collect usage statistics,
  analytics or any other data.
- **Licensing is done by the IDE and JetBrains.** When you start the trial or activate a license, the IDE checks it
  with JetBrains, using your JetBrains Account. JetBrains processes that data under the
  [JetBrains Privacy Policy](https://www.jetbrains.com/legal/docs/privacy/privacy/).

## Purchases

Licenses are sold by JetBrains through JetBrains Marketplace, which handles payments and invoices. See the
[JetBrains Privacy Policy](https://www.jetbrains.com/legal/docs/privacy/privacy/).

## Support emails

If you write to [florin@selfcloud.ro](mailto:florin@selfcloud.ro), your email is used only to answer you.

## This website

This website uses no cookies, no analytics and no tracking. It's hosted on GitHub Pages, and GitHub may log
technical data such as IP addresses under the
[GitHub General Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).
