title: FAQ
description: Common questions about Invisible Notes.
---

## Do notes change my files?

No. Notes are only drawn in the editor. The file on disk, and so your version control, never sees them. Even the
line numbers stay the same.

## Can my team see my notes?

No. Notes are stored on your computer only, outside the project, so they're never committed or pushed. See
[Where notes are stored](/invisible-notes/guides/storage/).

## Does Invisible Notes send my notes anywhere?

No. The plugin makes no network connections. The only online part is the license check, which the IDE does with
JetBrains. See [Privacy](/invisible-notes/licensing/privacy/).

Notes can leave your computer in one way: an AI tool that works with your IDE can read them. See the next
question.

## Can an AI tool read or change my notes?

Only one that works with your IDE. An AI tool connected to the IDE's MCP server can read, add, change and delete
all invisible notes of the projects you open, and what it reads is sent to the AI service behind it. That's how you get an AI tool to explain or review code with notes.

For AI tools outside the IDE, the MCP server is off until you turn it on. AI agents that run inside the IDE may be
given the same tools without that. See [Notes for AI tools](/invisible-notes/guides/ai-tools/).

## What happens when I switch branches?

Notes look for their code again. They stay with it if it moved, wait if their file doesn't exist on this branch, and
come back when you switch back. See [How notes follow your code](/invisible-notes/guides/following-code/).

## What happens when I move or rename the project's folder?

The notes stay with the project. See
[Moving, renaming and copying a project](/invisible-notes/guides/storage/#moving-renaming-and-copying-a-project).

## A note disappeared from the editor. Where did it go?

Its code was probably deleted or changed beyond recognition, so the note is now orphaned. Open the Invisible Notes
tool window, **All Files** tab: it's listed there as **orphaned: code not found**. It returns if its code does, and you
can delete it from there.

## I deleted a note by mistake.

Press <kbd>Ctrl+Z</kbd> (<kbd>⌘Z</kbd> on macOS) straight away. The note comes back.

## How do I delete all notes of a file, or all of them?

With the trash button in the Invisible Notes tool window, or **Delete All Invisible Notes in File** in the editor's
right-click menu. You're asked first, and Undo brings the notes back. See
[Delete all notes at once](/invisible-notes/guides/working-with-notes/#delete-all-notes-at-once).

## Does it work with languages other than PHP?

Yes. Notes work in any file of your project. In languages the IDE understands, notes also use the surrounding class
and function to find their line after bigger changes.

## Which IDEs does it support?

PhpStorm 2025.2 and newer, and other JetBrains IDEs from version 2025.2, such as IntelliJ IDEA and WebStorm.

In 2025.1 you get Invisible Notes 1.0.0. It has the notes, the scrollbar marks, the tool window and undo, but not
what was added in later versions: see the [release notes](/invisible-notes/reference/release-notes/).

## Can I use it after the trial ends?

With a license, yes. Without one, the IDE switches the plugin off. Your notes stay on disk, and reappear when you
activate a license. See [Pricing and trial](/invisible-notes/licensing/pricing/).
