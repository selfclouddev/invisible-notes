## 1.4.0

Needs IDE version 2025.2 or newer. In 2025.1, version 1.0.0 remains available.

If you're on a trial, the IDE asks for a license after this update: 1.4.0 is a new major version, and JetBrains
Marketplace then ends the trials that are running. Choose **Start trial** on that screen to get a new 30 days.

- **Delete all notes at once.** Delete every note of a file, or of the whole project, in one step: with the trash
  button in the Invisible Notes tool window, **Delete All Invisible Notes in File** in the editor's right-click menu,
  or **Delete All Invisible Notes in Project** in Find Action. You're asked first, and one Undo brings the notes
  back. See [Delete all notes at once](/invisible-notes/guides/working-with-notes/#delete-all-notes-at-once).
- **Notes stay with a moved project.** Move or rename a project's folder and its notes come along. Until now such a
  project started without notes. See
  [Moving, renaming and copying a project](/invisible-notes/guides/storage/#moving-renaming-and-copying-a-project).
- **Notes for AI tools.** An AI tool connected to the IDE's MCP server can list, add, change and delete notes, so
  it can explain or review code with notes and leave your files alone. A tool
  connected this way has access to all notes of the projects you open; the IDE tells you the first time one uses
  them. See [Notes for AI tools](/invisible-notes/guides/ai-tools/).

## 1.0.0

First release.

- Private notes above lines of code, never written into the file.
- Notes follow their code through edits, pulls, branch switches, and file renames and moves.
- Marks next to the scrollbar, and a note count in the editor's top-right corner.
- The Invisible Notes tool window, with **Current File** and **All Files** tabs.
- Undo for deleted notes.
- Notes stored in the shared JetBrains data folder, safe from Invalidate Caches.
