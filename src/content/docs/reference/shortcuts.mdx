---
title: Keyboard shortcuts
description: Keyboard shortcuts for adding, editing and restoring invisible notes.
---

| Action                                        | Windows and Linux              | macOS                  |
| --------------------------------------------- | ------------------------------ | ---------------------- |
| Add a note on the caret's line, or edit it    | <kbd>Ctrl+Alt+Shift+Z</kbd>    | <kbd>⌥⇧⌘Z</kbd>        |
| Save the note being written                   | <kbd>Enter</kbd>               | <kbd>Enter</kbd>       |
| Start a new line in a note                    | <kbd>Shift+Enter</kbd>         | <kbd>⇧Enter</kbd>      |
| Cancel writing                                | <kbd>Esc</kbd>                 | <kbd>Esc</kbd>         |
| Bring back a deleted note                     | <kbd>Ctrl+Z</kbd>              | <kbd>⌘Z</kbd>          |
| Delete it again                               | <kbd>Ctrl+Shift+Z</kbd>        | <kbd>⇧⌘Z</kbd>         |
| Tool window: open the selected note's file    | <kbd>Enter</kbd>               | <kbd>Enter</kbd>       |

## Changing the shortcut

Open **Settings → Keymap**, search for **Add Invisible Note**, and assign the keys you prefer. The shortcut is also
used for editing, on lines that already have a note.
